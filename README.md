# Simon-Game
A memory-based color pattern game built with HTML, CSS, and JavaScript. Recreate the sequence, level up, and test your memory power! 🎮🧠

## 📌 Features

- 🔁 Random color sequence generation on every level
- ✨ Visual feedback with button flashing effects
- 🧠 User input tracking and correctness checking
- ❌ Game Over detection with auto-reset functionality
- 🎯 Clean and responsive UI layout

## 🚀 How to Play

1. Press any key to start the game.
2. A button will flash—remember its color.
3. Click on the buttons in the same order they flashed.
4. With every level up, the sequence gets longer.
5. Make one wrong click, and it’s game over. Your final score will be shown!

## 🛠️ Tech Stack

- ✅ HTML – For page structure
- 🎨 CSS – For styling and button effects
- 🧠 JavaScript – For game logic and interactivity
